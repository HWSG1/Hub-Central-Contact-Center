# Calculadora Corta Cuotas 1.0.0

Módulo de prueba basado en el Excel proporcionado por el usuario. Implementación backend: apps/portal-api/src/business/corta-cuotas.ts; frontend: apps/portal-web/src/app/business/corta-cuotas.ts. La instalación administrativa la realiza el núcleo, no el módulo.

Importar corta-cuotas-1.0.0.hub.json desde Centro de módulos y publicar. El descriptor identifica exclusivamente código incorporado en esta versión del Hub. No contiene ejecutables ni autoriza acceso. La migración 005 registra los permisos; el uso requiere CORTA_CUOTAS.USE, módulo habilitado y catálogo publicado.

Ver [manual](../../manual-instalacion/10-modulos.md) para instalación, tarifario, controles, pruebas y límites de simulación.
