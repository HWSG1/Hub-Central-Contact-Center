# Instaladores históricos

La instalación vigente usa únicamente [manual-instalacion/sql/Instalar-Actualizar-Hub.sql](../../manual-instalacion/sql/Instalar-Actualizar-Hub.sql). Ver [manual](../../manual-instalacion/README.md).

Install-Local.sql, Update-Security-Administration.sql y Update-User-Enrollment.sql se conservan para rastrear entregas anteriores. No combinarlos con el instalador vigente ni usarlos para una instalación nueva. Las migraciones originales se mantienen intactas y los hashes siguen siendo compatibles.
